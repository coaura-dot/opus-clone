3. COMO ENTREGAR CADA ATUALIZAÇÃO (formato que ele espera)
---------------------------------------------------------
a) Subir a versão em src/version.py (VERSION = "vNN"). Ela vai no
   .meta.json de cada corte (campo "versao") e aparece no log ao ligar.
b) Lint (python3 -m pyflakes nos arquivos mexidos) e
   python3 test_pipeline.py  (tem que terminar com "TESTE OK").
c) Commit + push.
d) Zip no scratchpad:
     git archive --format=zip --prefix=AutoClipper/ -o <scratchpad>/AutoClipper-vNN.zip HEAD
   conferir: unzip -l ... | grep -c "credentials/\|youtube_token\|client_secret.json\|claude_api_key"  -> tem que dar 0
e) Mandar o zip com SendUserFile (display "attach") e, na resposta, este
   bloco de PowerShell (trocar vNN em todos os lugares):

& {
  $zip  = "$env:USERPROFILE\Downloads\AutoClipper-vNN.zip"
  $dest = "C:\Users\igo\Desktop\opus-clip-clone\opus-clip-clone"
  if (-not (Test-Path $zip)) { Write-Host "Nao achei $zip (baixou pra outra pasta?)" -ForegroundColor Red; return }
  $hb = "$dest\autopilot_data\piloto_ligado.json"
  if ((Test-Path $hb) -and ((Get-Date) - (Get-Item $hb).LastWriteTime).TotalSeconds -lt 30) {
    Write-Host "O piloto ainda esta ligado. Feche o Auto Clipper (clique Sim pra desligar) e rode de novo." -ForegroundColor Yellow; return }
  $tmp = Join-Path $env:TEMP "ac_vNN"
  if (Test-Path $tmp) { Remove-Item $tmp -Recurse -Force }
  Expand-Archive $zip $tmp -Force
  robocopy "$tmp\AutoClipper" $dest /E /XD .venv whisper.cpp output credentials autopilot_data .autoclip_work models /NFL /NDL /NJH /NJS /NP | Out-Null
  if (Select-String -Path "$dest\src\version.py" -Pattern 'vNN' -Quiet) { Write-Host "vNN instalada." -ForegroundColor Green }
  else { Write-Host "Algo deu errado na copia." -ForegroundColor Red; return }
  $pyw = "$dest\.venv\Scripts\pythonw.exe"
  if (Test-Path $pyw) { Start-Process $pyw -ArgumentList "`"$dest\interface.py`" --ligar" -WorkingDirectory $dest }
  else { Start-Process "$dest\AUTO_CLIPPER.bat" -WorkingDirectory $dest }
}

   (Avisar pra fechar o Auto Clipper antes, clicando "Sim" pra desligar.)

   ainda NÃO cobre. Lembrar que clipes que já estão na fila foram editados
   pela versão antiga (o campo "versao" do .meta.json mostra qual).

6. MAPA DO CÓDIGO (o que importa)
---------------------------------
main.py ............ pipeline de um vídeo: baixa, detecta react clássico
                     (react_layout), transcreve (vídeo > 39 min: blocos de 20
                     min em long_video.py), escolhe trechos (clip_selector),
                     ESTENDE react (react_extend), edita (video_editor.build_clip)
autopilot.py (raiz) + src/autopilot.py ... piloto automático (fila, nota,
                     postagem, modos, freio de alcance, só postar)
interface.py ....... a interface (Tkinter, roda no pythonw)
src/control.py ..... arquivos de controle em autopilot_data/: piloto_ligado.json
                     (batimento), parar.pedido, modo_gpu.txt, modo_trabalho.txt,
                     posts_por_dia.txt
src/reach.py ....... freio automático: lê views dos próprios Shorts (API, 1
                     unidade a cada 2 h); 3 últimos maduros (8 h+) com <5% da
                     mediana anterior -> 1 post a cada 8 h até voltar
src/channel_check.py "já está no canal?" antes de cada upload (histórico de
                     todos os canais + uploads do canal que recebe)
src/accounts.py .... (v46) vários canais: credentials/contas.json (c1 = canal
                     antigo, youtube_token.json; novos = id UC..., token
                     youtube_token_<id>.json), login() (escolhe conta, canal
                     repetido só troca o login), sub(state, acc) = pedaço do
                     state.json de cada canal (last_post_at, blocked_until,
                     reach_brake, uploads_playlist, auth_down...),
                     posted[].account (sem = c1), migrate_state
src/throttle.py .... limite de GPU (suspende/retoma processos)
src/video_editor.py  build_clip: jump cuts, legenda, música, plano de cenas,
                     render; grava .meta.json ("versao") e clip_XX.origem.jpg
                     (8 quadros do original)
src/reframer.py .... render vertical; _compose_split_frame (imagem em cima,
                     pessoa embaixo)
src/shot_plan.py ... plano por cena: single/multi/speaker/broll/text/facefit/
                     split. Tela dividida (costura vertical) + janela de
                     conteúdo (_window_shot) + filtro de "piscar" (<2 s)
src/content_window.py janela de conteúdo por cima da câmera (v37)
src/react_layout.py  react clássico (facecam em caixa sobre o conteúdo);
                     _content_over_cam evita confundir janela de vídeo com facecam.
                     v41: plan_clip analisa a 8 qps (cortes do conteúdo, rostos,
                     texto), _geometry (painel alto x largura inteira, tamanho
                     do painel do streamer), _place_shot (enquadramento parado
                     por plano), _cam_shots (tripé), ReactClipPlan.compose
                     (troca no quadro exato do corte)
src/reframer.py .... (também) crop_scaled (recorte com fração, sem degrau) e
                     hq_resize (Lanczos + realce antes de ampliar)
src/react_extend.py  (v40) corte pega o conteúdo reagido inteiro
src/voices.py ...... "impressão digital" da voz (WeSpeaker ONNX no
                     onnxruntime): embed, who_speaks(ref=...), embed_phrases
src/gameplay.py .... modo gameplay (canal marcado com |game): streamer x jogo,
                     voz de outro jogador mostra o jogo, cortes secos
src/react_detector.py padrões de fala apontando imagem ("essa moça aqui")
src/clip_selector.py escolha dos trechos (limites de assunto, duração)
src/config.py ...... todos os ajustes (comentados em português)
